# Chrome Profile Dashboard — Releases

ที่ปล่อยอัปเดตของโปรแกรม Chrome Profile Dashboard (เว็บ dashboard สำหรับค้นหา/เปิด/จัดกลุ่ม Chrome profiles ในเครื่อง)

- `version.json` — เวอร์ชันล่าสุด + ลิงก์ดาวน์โหลด (ตัวโปรแกรมเช็คไฟล์นี้)
- ไฟล์ .exe อยู่ใน [Releases](https://github.com/tac29ad1-blip/chrome-dashboard-releases/releases)

ดาวน์โหลดครั้งแรก: หน้า Releases → ไฟล์ `ChromeProfileDashboard.exe` — หลังจากนั้นโปรแกรมจะแจ้งเตือนและอัปเดตตัวเองได้จากในหน้า Dashboard
